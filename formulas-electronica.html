Componentes Pasivos
Resistencias
Ley de Ohm
V = I · R
En Serie
R_total = R₁ + R₂ + R₃ + ...
En Paralelo
1/R_total = 1/R₁ + 1/R₂ + 1/R₃ + ...
Dos en paralelo: R_t = R₁·R₂ / (R₁+R₂)
Condensadores
Carga almacenada
Q = C · V
Corriente
I = C · dV/dt
En Serie
1/C_total = 1/C₁ + 1/C₂ + ...
En Paralelo
C_total = C₁ + C₂ + C₃ + ...
Inductores
Tensión inducida
V = L · dI/dt
En Serie
L_total = L₁ + L₂ + L₃ + ...
En Paralelo
1/L_total = 1/L₁ + 1/L₂ + ...
Circuitos Eléctricos
Divisor de Tensión
V_k = (R_k / R_total) · V_total
  • V_k — Tensión en la resistencia k [V]
  • R_k — Resistencia k [Ω]
  • R_total — Resistencia total del circuito [Ω]
Divisor de Intensidad
I_k = (R_total / R_k) · I_total
Potencia Eléctrica
P = V · I = I² · R = V² / R
  • P — Potencia [W]
  • V — Voltaje [V]
  • I — Corriente [A]
  • R — Resistencia [Ω]
Análisis de Circuitos
Ley de Kirchhoff para Corrientes (KCL)
ΣI_entrantes − ΣI_salientes = 0
La suma algebraica de corrientes que entran y salen de un nodo es igual a cero.
Ley de Kirchhoff para Voltajes (KVL)
ΣV_lazo = 0
La suma algebraica de las diferencias de potencial en cualquier lazo cerrado es cero.
Método de Nudos
1. Identificar todos los nodos y elegir referencia (tierra).
2. Aplicar KCL en cada nodo no referencia.
3. Resolver el sistema de ecuaciones resultante.
Método de Mallas
1. Identificar todas las mallas independientes del circuito.
2. Aplicar KVL en cada malla.
3. Resolver el sistema de ecuaciones resultante.
Teoremas y Sustituciones
Teorema de Superposición
En un circuito lineal con múltiples fuentes independientes, la respuesta en cualquier elemento es la suma algebraica de las respuestas debidas a cada fuente actuando sola (con las demás apagadas).
Apagar todas menos una → calcular respuesta → repetir → sumar algebraicamente.
Teorema de Thévenin
Cualquier circuito lineal de dos terminales se reemplaza por V_th en serie con R_th.
  • V_th — Voltaje de circuito abierto entre terminales [V]
  • R_th — Resistencia equivalente (fuentes independientes apagadas) [Ω]
Teorema de Norton
Cualquier circuito lineal de dos terminales se reemplaza por I_n en paralelo con R_n.
  • I_n — Corriente de cortocircuito entre terminales [A]
  • R_n — Resistencia equivalente = R_th [Ω]
Teorema de Millman
Tensión en nodo común
V_out = Σ(V_i/R_i) / Σ(1/R_i)
Simplifica circuitos con múltiples fuentes de voltaje en paralelo con resistencias.
Valor Eficaz RMS
V_rms = V_max / √2 ≈ 0.707 · V_max
I_rms = I_max / √2
Utilizado en análisis de CA para calcular potencia: P = V_rms · I_rms.
Dispositivos Electrónicos Activos
Definición
Son aquellos que pueden controlar el flujo de corriente en un circuito y proporcionar energía o amplificación.
A diferencia de los componentes pasivos (R, C, L), los activos requieren una fuente de energía externa para funcionar.
Ejemplos: diodos, transistores BJT, FET/MOSFET, tiristores, amplificadores operacionales.
Diodos
Diodo de Unión PN
Permite el flujo de corriente en una dirección (polarización directa) y bloquea en la opuesta.
Diodo ideal
V_D = 0 si I_D > 0 (directa)
I_D = 0 si V_D < 0 (inversa bloqueada)
Ecuación de Shockley
I_D = I_S · (e^(V_D / n·V_T) − 1)
V_T = k·T/q ≈ 26 mV (a 25°C)
  • I_S — Corriente de saturación inversa [A]
  • n — Factor de idealidad (1–2)
  • V_T — Voltaje térmico [V]
  • k — Constante de Boltzmann = 1.38×10⁻²³ J/K
  • q — Carga del electrón = 1.6×10⁻¹⁹ C
Caída de tensión directa (práctica)
Silicio: V_D ≈ 0.6–0.7 V
Germanio: V_D ≈ 0.2–0.3 V
Schottky: V_D ≈ 0.2–0.4 V
LED rojo: V_D ≈ 1.8–2.2 V
Diodo Zener (regulación de voltaje)
Opera en polarización inversa. Mantiene voltaje constante V_Z.
V_salida = V_Z
R_serie = (V_in − V_Z) / I_total
La corriente mínima de Zener I_Z_min garantiza regulación estable.
Resistencia limitadora para LED
R = (V_cc − V_LED) / I_LED
  • V_cc — Tensión de alimentación [V]
  • V_LED — Caída en el LED [V]
  • I_LED — Corriente deseada [A] (típico 10–20 mA)
Transistores Bipolares (BJT)
Principio de funcionamiento
Dispositivos semiconductores NPN o PNP. Un transistor BJT controla la corriente a través del terminal Colector en función de la corriente de Base.
Corrientes y ganancia
I_C = β · I_B = α · I_E
I_E = I_B + I_C = I_B · (1 + β)
α = β / (1 + β) | β = α / (1 − α)
  • β (hFE) — Ganancia de corriente DC (20–500 típico)
  • α — Ganancia en base común (≈ 0.95–0.999)
  • I_C, I_B, I_E — Corrientes colector/base/emisor [A]
Condiciones de Polarización
Polarización directa (activa)
V_BE ≈ 0.6–0.7 V (silicio NPN)
V_CE > V_CE_sat para modo activo
Saturación (switch ON)
V_CE_sat ≈ 0.1–0.3 V
I_B_min = I_C_sat / β
I_C_sat = (V_cc − V_CE_sat) / R_C
Corte (switch OFF)
I_B = 0 → I_C ≈ 0
Polarización por divisor de tensión
V_B = V_cc · R₂ / (R₁ + R₂)
V_E = V_B − V_BE
I_C ≈ I_E = V_E / R_E
V_CE = V_cc − I_C·(R_C + R_E)
Cálculo de Potencia
Potencia de salida
P_out = V_CE · I_C
Potencia disipada en el transistor
P_diss = V_CE · I_C
P_diss no debe superar P_max del datasheet. Usar disipador si P_diss > 1 W.
Configuraciones de Transistor
Emisor Común (CE)
Ganancia de voltaje y corriente alta. Inversión de señal. Uso: amplificación general.
A_v = −g_m · R_C | A_i = β
Colector Común — Seguidor de Emisor (CC)
Alta impedancia de entrada, baja impedancia de salida. Sin inversión.
A_v ≈ 1 | Útil como buffer de impedancia
Base Común (CB)
Alta impedancia de salida. Sin inversión. Útil en radiofrecuencia.
A_i ≈ 1 | A_v = g_m · R_C
Transconductancia y frecuencia
g_m = I_C / V_T [A/V]
f_T = β · f_β = g_m / (2π · C_π)
  • f_T — Frecuencia de transición (ganancia = 1)
  • g_m — Transconductancia [S]
Transistores de Efecto de Campo (FET)
Tipos de FET
JFET: Unión PN para controlar el canal. Alta resistencia de entrada. Controlado por V_GS.
MOSFET: Capa de óxido entre puerta y canal. Mayor flexibilidad. Uso digital y conmutación.
Regiones de Operación
Corte
V_GS < V_th → I_D = 0
Saturación (amplificación)
V_GS > V_th → I_D ≈ constante
MOSFET: I_D = (Kn/2) · (V_GS − V_th)²
Triodo / Lineal (V_DS pequeño)
I_D = Kn·[(V_GS−V_th)·V_DS − V_DS²/2]
Comporta como resistencia controlada por V_GS
Ecuación del JFET (corriente de drenaje)
I_D = I_DSS · (1 − V_GS / V_GS_off)²
  • I_DSS — Corriente de saturación con V_GS = 0 [A]
  • V_GS_off — Tensión de pinch-off [V]
Configuraciones de FET
Fuente Común (CS) — equivale a Emisor Común
Alta ganancia de voltaje. Inversión de señal. A_v = −g_m · R_D
Drenaje Común — Seguidor de Fuente (CD)
Alta Rin, baja Rout. A_v ≈ 1. Sin inversión. Equivale a Colector Común.
Puerta Común (CG)
Baja Rin. Sin inversión. Uso en RF. A_v = g_m · R_D
MOSFET: Transconductancia y conmutación
g_m = √(2 · Kn · I_D) [A/V]
R_DS(on) = 1 / (Kn · (V_GS − V_th)) [Ω]
Pérdidas totales en conmutación
P_cond = I_D² · R_DS(on)
P_sw = ½ · V_DS · I_D · (t_on + t_off) · f_sw
P_total = P_cond + P_sw
Filtros y Osciladores
Filtro RC Pasivo
Frecuencia de corte (−3 dB)
f_c = 1 / (2π · R · C)
τ = R · C (constante de tiempo)
Ganancia a cualquier frecuencia
|A| = 1 / √(1 + (f/f_c)²)
|A|_dB = −20·log₁₀(f/f_c) (por encima de f_c)
Filtro RL
f_c = R / (2π · L)
τ = L / R
Filtro Activo Sallen-Key (2º orden)
f_c = 1 / (2π · √(R₁·R₂·C₁·C₂))
Q = √(R₁·R₂·C₁·C₂) / (C₂·(R₁+R₂))
Butterworth: Q = 0.707 → pendiente −40 dB/dec
Osciladores
Oscilador RC (frecuencia de oscilación)
f = 1 / (2π · R · C)
Oscilador LC (frecuencia de resonancia)
f = 1 / (2π · √(L · C))
Condición de Barkhausen: ganancia de lazo = 1 y desfase = 0° (o múltiplo de 360°).
Rectificadores
Rectificador de Media Onda
Utiliza un único diodo. Solo pasa un semiciclo de la señal AC.
V_avg = V_max / π ≈ 0.318 · V_max
Rectificador de Onda Completa (puente)
Usa 4 diodos en puente. Pasa ambos semiciclos.
V_avg = 2·V_max / π ≈ 0.636 · V_max
V_rizado ≈ I_carga / (f · C) [V_pp]
  • V_max — Tensión pico de entrada [V]
  • f — Frecuencia de red [Hz] (50 o 60 Hz)
  • C — Capacitor de filtro [F]
Eficiencia de Rectificación
η = (P_out / P_in) · 100%
Media onda: η_max ≈ 40.6%
Onda completa: η_max ≈ 81.2%
Filtros de Salida
Para suavizar la señal rectificada se usan condensadores. Reducen el rizado de la salida.
C = I_carga / (f · V_rizado)
Mayor C → menor rizado → más estable la tensión DC de salida.
Tipos de Filtros
Filtros Pasa Bajos (LPF)
Permiten el paso de frecuencias por debajo de la frecuencia de corte f_c.
f_c = 1 / (2π · R · C)
Filtros Pasa Altos (HPF)
Permiten el paso de frecuencias por encima de la frecuencia de corte f_c.
f_c = 1 / (2π · R · C)
Filtros Pasa Banda (BPF)
Permiten el paso de un rango específico de frecuencias.
Frecuencia central
f₀ = √(f_c1 · f_c2)
Ancho de banda
BW = f_c2 − f_c1
Filtros Rechaza Banda (BSF / Notch)
Atenúan un rango específico de frecuencias. Opuesto al BPF.
f_notch = 1 / (2π · √(R₁·R₂·C₁·C₂))
Filtro RC Pasa Bajos (función de transferencia)
H(s) = 1 / (1 + s·R·C)
|H(jω)| = 1 / √(1 + (ω/ω_c)²)
Amplificadores Operacionales (Op-Amp)
Definición
Dispositivos amplificadores de ganancia muy alta. Se usan en configuraciones inversor, no inversor, sumador, diferenciador, integrador, etc.
Amplificador Inversor
Ganancia de voltaje
A_v = −R_f / R_in
V_out = −(R_f / R_in) · V_in
Amplificador No Inversor
Ganancia de voltaje
A_v = 1 + R_f / R_in
V_out = (1 + R_f/R_in) · V_in
Seguidor de tensión (buffer)
A_v = 1 (R_f = 0, R_in = ∞)
Sumador Inversor
V_out = −R_f · (V₁/R₁ + V₂/R₂ + V₃/R₃)
Amplificador Diferencial
V_out = (R_f/R₁) · (V₂ − V₁)
CMRR = A_dif / A_común [dB]
Integrador y Derivador
Integrador
V_out = −(1/RC) · ∫V_in dt
Derivador
V_out = −R·C · dV_in/dt
Parámetros importantes
Slew Rate (velocidad de cambio)
SR = dV/dt_max [V/μs]
f_max = SR / (2π · V_pico)
Producto Ganancia × Ancho de Banda
GBW = A_v · BW = constante
ADC, DAC y PWM
Conversor ADC
Resolución = V_ref / (2ⁿ − 1)
Código = V_entrada / Resolución
n bits → 2ⁿ niveles
  • n — Número de bits
  • 8 bits → 256 niveles · 10 bits → 1024 · 12 bits → 4096
  • ADC 10 bits, 5 V_ref → resolución ≈ 4.9 mV
PWM (Modulación por Ancho de Pulso)
V_media = V_cc · D
D = t_on / T (duty cycle, 0–1)
T = 1/f_pwm (período)
PWM + filtro RC → DAC simple: f_corte_filtro ≪ f_PWM para buen filtrado.
