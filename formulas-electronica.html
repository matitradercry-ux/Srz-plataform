Diodos · BJT · MOSFET · Op-Amp · Filtros · ADC/PWM

Diodos
Ecuación de Shockley
I_D = I_s · (e^(V_D / n·V_T) − 1)
V_T = k·T/q ≈ 26 mV (a 25°C)
  • I_s — Corriente de saturación inversa [A]
  • V_T — Tensión térmica [V]
  • n — Factor de idealidad (1–2)
  • k = 1.38×10⁻²³ J/K · q = 1.6×10⁻¹⁹ C
Caída de tensión directa (práctica)
Silicio: V_D ≈ 0.6–0.7 V
Germanio: V_D ≈ 0.2–0.3 V
Schottky: V_D ≈ 0.2–0.4 V
LED rojo: V_D ≈ 1.8–2.2 V
Resistencia limitadora para LED
R = (V_cc − V_LED) / I_LED
  • V_cc — Tensión de alimentación [V]
  • V_LED — Caída en el LED [V]
  • I_LED — Corriente deseada [A] (típico 10–20 mA)
Rectificadores
Media onda
V_dc = V_pico / π = 0.318 · V_pico
Onda completa (puente)
V_dc = 2·V_pico / π = 0.636 · V_pico
V_rizado = I_carga / (f · C) [V_pp]
Diodo Zener (regulación)
V_salida = V_Z (tensión de ruptura)
R_serie = (V_in − V_Z) / I_total
I_Z_min = I_carga_max · 0.1 (margen)
Transistor BJT
Corrientes y ganancia
I_C = β · I_B = α · I_E
I_E = I_B + I_C = I_B · (1 + β)
α = β / (1 + β) β = α / (1 − α)
  • β (hFE) — Ganancia de corriente DC (20–500 típico)
  • α — Ganancia en base común (≈0.95–0.999)
  • I_C, I_B, I_E — Corrientes colector/base/emisor [A]
Polarización divisor de tensión
V_B = V_cc · R₂ / (R₁ + R₂)
V_E = V_B − V_BE (V_BE ≈ 0.6–0.7 V)
I_C ≈ I_E = V_E / R_E
V_CE = V_cc − I_C·(R_C + R_E)
Saturación (switch)
I_B_min = I_C_sat / β
I_C_sat = (V_cc − V_CE_sat) / R_C
V_CE_sat ≈ 0.1–0.3 V
Sobredimensionar I_B al doble o triple de I_B_min garantiza saturación completa.
Ganancia en frecuencia
f_T = β · f_β = g_m / (2π · C_π)
g_m = I_C / V_T [A/V]
  • f_T — Frecuencia de transición (unidad-gain)
  • g_m — Transconductancia [S]
Transistor MOSFET
Zonas de operación (canal N, enriquecimiento)
Corte
V_GS < V_th → I_D = 0
Lineal / Óhmica (V_DS < V_GS − V_th)
I_D = Kn·[(V_GS−V_th)·V_DS − V_DS²/2]
Saturación (V_DS ≥ V_GS − V_th)
I_D = (Kn/2) · (V_GS − V_th)²
  • V_th — Tensión de umbral [V]
  • Kn — Parámetro de proceso [A/V²]
  • V_GS, V_DS — Tensiones gate-source / drain-source [V]
Transconductancia y resistencia en ON
g_m = √(2 · Kn · I_D) [A/V]
R_DS(on) = 1 / (Kn · (V_GS − V_th)) [Ω]
Pérdidas en conmutación
P_cond = I_D² · R_DS(on)
P_sw = ½ · V_DS · I_D · (t_on + t_off) · f_sw
P_total = P_cond + P_sw + P_gate
Amplificador Operacional (Op-Amp)
Amplificador inversor
A_v = −R_f / R₁
V_sal = −(R_f / R₁) · V_ent
Amplificador no inversor
A_v = 1 + R_f / R₁
Seguidor de tensión: A_v = 1 (R_f = 0, R₁ = ∞)
Sumador inversor
V_sal = −R_f · (V₁/R₁ + V₂/R₂ + V₃/R₃)
Integrador y derivador
Integrador
V_sal = −(1/RC) · ∫V_ent dt
Derivador
V_sal = −R·C · dV_ent/dt
Amplificador diferencial
V_sal = (R_f/R₁) · (V₂ − V₁)
CMRR = A_dif / A_común [dB]
Slew rate y ancho de banda
SR = dV/dt_max [V/μs]
f_max = SR / (2π · V_pico)
GBW = A_v · BW = cte (producto ganancia×ancho de banda)
Filtros RC y RL
Filtro RC pasivo
Frecuencia de corte (−3 dB)
f_c = 1 / (2π · R · C)
τ = R · C (constante de tiempo)
Ganancia a cualquier frecuencia
|A| = 1 / √(1 + (f/f_c)²)
|A|_dB = −20·log₁₀(f/f_c) (por encima de f_c)
Filtro RL
f_c = R / (2π · L)
τ = L / R
Filtro activo Sallen-Key (2º orden)
f_c = 1 / (2π · √(R₁·R₂·C₁·C₂))
Q = √(R₁·R₂·C₁·C₂) / (C₂·(R₁+R₂))
Butterworth: Q = 0.707 → pendiente −40 dB/década
ADC, DAC y PWM
Conversor ADC
Resolución = V_ref / (2ⁿ − 1)
Código = V_entrada / Resolución
n bits → 2ⁿ niveles
  • n — Número de bits (8 bits → 256 niveles · 12 bits → 4096)
  • ADC 10 bits, 5 V_ref → resolución = 5/1023 ≈ 4.9 mV
PWM
V_media = V_cc · D
D = t_on / T (duty cycle, 0–1)
T = 1/f_pwm (período)
PWM + filtro RC → DAC simple: f_corte_filtro ≪ f_PWM para buen filtrado.
