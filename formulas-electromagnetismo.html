Ecuaciones de Maxwell · Ondas EM · Campos · Energía · Antenas

Ecuaciones de Maxwell
Ley de Gauss (campo eléctrico)
Forma integral
∮ E·dA = Q_enc / ε₀
Forma diferencial
∇·E = ρ / ε₀
  • Q_enc — Carga encerrada [C]
  • ε₀ = 8.85×10⁻¹² F/m
  • ρ — Densidad volumétrica de carga [C/m³]
Ley de Gauss (campo magnético)
Forma integral
∮ B·dA = 0
Forma diferencial
∇·B = 0
No existen monopolos magnéticos: las líneas de B siempre son cerradas.
Ley de Faraday (inducción)
Forma integral
∮ E·dl = −dΦ_B/dt
Forma diferencial
∇×E = −∂B/∂t
Ley de Ampère-Maxwell
Forma integral
∮ B·dl = μ₀·(I + ε₀·dΦ_E/dt)
Forma diferencial
∇×B = μ₀·J + μ₀·ε₀·∂E/∂t
  • μ₀ = 4π×10⁻⁷ H/m
  • J — Densidad de corriente [A/m²]
Ondas Electromagnéticas
Velocidad de la luz y longitud de onda
c = 1 / √(μ₀·ε₀) = 3×10⁸ m/s
v = c / √(μᵣ·εᵣ) (en un medio)
λ = v / f = c / f (en vacío)
Vector de Poynting (densidad de potencia)
S = E × H [W/m²]
|S| = E · H = E² / η = H² · η
η₀ = √(μ₀/ε₀) ≈ 377 Ω (impedancia del vacío)
Efecto pelicular (skin depth)
δ = √(2 / (ω·μ·σ)) = √(ρ / (π·f·μ))
  • δ — Profundidad de penetración [m]
  • σ — Conductividad eléctrica [S/m]
  • ρ — Resistividad [Ω·m]
  • Cu a 1 MHz: δ ≈ 66 μm · Cu a 100 MHz: δ ≈ 6.6 μm
Efecto Doppler
f_obs = f_emit · (c ± v_obs) / (c ∓ v_fuente)
+ cuando se acercan, − cuando se alejan. Para radar: Δf = 2·v·f/c (velocidad radial v).
Espectro electromagnético
Radio: λ > 1 mm (f < 300 GHz)
Microondas: 1 mm – 1 m (300 MHz – 300 GHz)
Infrarrojo: 700 nm – 1 mm
Visible: 380 – 700 nm
UV: 10 – 380 nm · X: 0.01 – 10 nm · γ: < 0.01 nm
Campo Eléctrico — Geometrías
Carga puntual
E = k·Q / r² = Q / (4πε₀·r²)
V = k·Q / r
Esfera conductora cargada
Fuera (r > R)
E = Q / (4πε₀·r²)
Dentro (r < R)
E = 0
Plano infinito cargado
E = σ / (2ε₀) [V/m]
σ — densidad superficial de carga [C/m²]
Cilindro conductor
E = λ / (2πε₀·r) [V/m]
λ — densidad lineal de carga [C/m]
Campo Magnético — Geometrías
Conductor recto infinito
B = μ₀·I / (2π·r) [T]
  • r — distancia perpendicular al conductor [m]
  • I — corriente [A]
Solenoide
B = μ₀·μᵣ·N·I / l = μ₀·μᵣ·n·I
n = N/l (espiras por metro)
Toroide
B = μ₀·μᵣ·N·I / (2π·R)
R — radio medio del toroide [m]
Fuerza entre conductores paralelos
F/L = μ₀·I₁·I₂ / (2π·d) [N/m]
Corrientes iguales → atracción · opuestas → repulsión
Energía Electromagnética
Energía almacenada en campos
En campo eléctrico
u_E = ½·ε₀·E² [J/m³]
En campo magnético
u_B = B² / (2μ₀) [J/m³]
En un inductor
W_L = ½·L·I² [J]
En un condensador
W_C = ½·C·V² = Q²/(2C) [J]
Antenas y Líneas de Transmisión
Longitud de antena dipolo
Dipolo de media onda (λ/2)
L = λ/2 = c / (2·f)
Monopulo de cuarto de onda (λ/4)
L = λ/4 = c / (4·f)
Factor de velocidad del cable coaxial típico: 0.66–0.85 → longitud eléctrica real = L / V_f.
Ecuación de Friis (enlace de radio)
P_r = P_t · G_t · G_r · (λ/4πd)²
P_r/P_t [dB] = G_t + G_r − 20·log(4πd/λ)
  • P_t, P_r — Potencia transmitida/recibida [W]
  • G_t, G_r — Ganancia antenas TX/RX (lineal)
  • d — Distancia [m]
  • λ — Longitud de onda [m]
ROE / VSWR (líneas de transmisión)
Γ = (Z_carga − Z₀) / (Z_carga + Z₀)
VSWR = (1 + |Γ|) / (1 − |Γ|)
P_reflejada = |Γ|² · P_incidente
RL = −20·log|Γ| [dB] (pérdida de retorno)
  • Z₀ — Impedancia característica de la línea (típico 50 Ω)
  • Γ — Coeficiente de reflexión (0 = sin reflexión)
  • VSWR = 1 → adaptación perfecta · VSWR < 2 aceptable
Impedancia característica de línea coaxial
Z₀ = (138 / √εᵣ) · log₁₀(D/d) [Ω]
D — diámetro interior del escudo · d — diámetro del conductor
