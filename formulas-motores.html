Mecánica Rotacional
Potencia, par y velocidad
P = T · ω = T · 2πn/60
T [N·m] = P [W] / ω [rad/s]
P [W] = T · n · π / 30
  • T — Par [N·m] · ω — Velocidad angular [rad/s]
  • n — RPM · ω = 2πn/60
Inercia y aceleración
T_neto = J · α = J · dω/dt
J_cilindro = ½ · m · r² [kg·m²]
t_aceleración = J · Δω / T_medio
Eficiencia mecánica
η = P_salida / P_entrada = T_carga · ω / (V · I)
Motor bien seleccionado opera a 75–100 % de carga nominal para η máxima.
Motor de Inducción (AC)
Velocidad sincrónica y deslizamiento
n_s = 120 · f / p [RPM]
s = (n_s − n) / n_s
n = n_s · (1 − s)
  • p — Número de polos · f — Frecuencia [Hz]
  • s nominal: 2–5 % · s_arranque: 100 % (rotor bloqueado)
Par del motor de inducción
T = (3 · V₁² · R₂/s) / (ω_s · [(R₁+R₂/s)² + X²])
T_max cuando s = R₂ / √(R₁² + X²)
Corriente de arranque y factor de potencia
I_arranque ≈ 5–8 · I_nominal
cos φ_nominal ≈ 0.8–0.9 · cos φ_vacío ≈ 0.1–0.3
Q_compensar = P · (tan φ₁ − tan φ₂) [VAR]
Motor trifásico — potencia
P = √3 · V_L · I_L · cos φ
S = √3 · V_L · I_L [VA] · Q = S · sin φ [VAR]
Motor DC
Ecuación fundamental del motor DC
V = E_b + I_a · R_a
E_b = K · φ · ω (fuerza contra-electromotriz)
T = K · φ · I_a
  • E_b — FCEM [V] · R_a — Resistencia armadura [Ω]
  • K — Constante constructiva · φ — Flujo [Wb]
Velocidad del motor DC
n = (V − I_a · R_a) / (K · φ)
Control de velocidad: variar V, variar R_a, variar φ
Motor DC sin escobillas (BLDC)
Kv = n / V [RPM/V]
n = Kv · V_alimentación (sin carga)
P = I · V · η
Kv 1000 + V=12V → n≈12000 RPM sin carga. Con carga baja según par y I.
Motores Especiales
Motor paso a paso
θ_paso = 360° / (N_polos · N_fases)
Paso típico: 1.8° (200 pasos/rev) · 0.9° (400 pasos/rev)
v_angular = pasos/s × θ_paso
Servo motor — control PWM
t_pulso: 1 ms = −90° · 1.5 ms = 0° · 2 ms = +90°
Período = 20 ms (50 Hz)
Motor universal (AC/DC)
T ∝ I² · n ∝ V / √T
Control de velocidad por ángulo de disparo TRIAC (fase)
Selección de Motores
Potencia requerida
P_motor = P_carga / (η_trans · η_motor)
Sobredimensionar 15–25 % para arranques frecuentes
Clases de aislamiento y temperatura
Clase A: 105°C · B: 130°C · F: 155°C · H: 180°C
T_bobinado = T_amb + ΔT_clase
Grado de protección IP
IP 2X — protección dedos · IP 5X — polvo · IP 6X — hermético
IP X4 — salpicaduras · IP X5 — chorro · IP X8 — sumersión
Motor de bomba sumergible mínimo IP68. Motor exterior mínimo IP55.
