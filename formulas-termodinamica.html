🌡 Termodinámica

Temperatura · Leyes · Gases ideales · Procesos · Ciclos · Transferencia de calor

Temperatura y Calor
Conversión de escalas
K = °C + 273.15
°F = °C × 9/5 + 32
°C = (°F − 32) × 5/9
  • 0 K = −273.15 °C (cero absoluto)
  • 0 °C = 32 °F · 100 °C = 212 °F
Calor sensible
Q = m · c · ΔT
  • m — Masa [kg]
  • c — Calor específico [J/kg·K]
  • ΔT — Variación de temperatura [K]
c_agua = 4186 · c_Al = 900 · c_Cu = 385 · c_Fe = 450 · c_aire = 1005 [J/kg·K]
Calor latente
Q = m · L
  • L — Calor latente [J/kg]
  • L_fusión agua = 334 kJ/kg · L_vaporización agua = 2260 kJ/kg
Dilatación térmica
Lineal
ΔL = α · L₀ · ΔT
Volumétrica
ΔV = β · V₀ · ΔT ≈ 3α · V₀ · ΔT
  • α_Al = 23×10⁻⁶ · α_Cu = 17×10⁻⁶ · α_Fe = 12×10⁻⁶ [1/K]
Leyes de la Termodinámica
1ª Ley — Conservación de energía
ΔU = Q − W
Q = ΔU + W
W = P · ΔV (presión constante)
  • ΔU — Variación de energía interna [J]
  • Q — Calor absorbido [J] (+ entra al sistema)
  • W — Trabajo realizado [J] (+ expande)
2ª Ley — Entropía
ΔS ≥ Q / T
ΔS = Q_rev / T (proceso reversible)
S = k_B · ln(W) (Boltzmann)
  • S — Entropía [J/K]
  • k_B = 1.38×10⁻²³ J/K
En un sistema aislado la entropía nunca decrece: ΔS_universo ≥ 0.
Gases Ideales
Ley del gas ideal
P · V = n · R · T
P · V = N · k_B · T
  • P — Presión [Pa] · V — Volumen [m³]
  • n — Moles [mol] · R = 8.314 J/mol·K
  • N — Número de moléculas
Leyes de gases
Boyle (T = cte)
P₁V₁ = P₂V₂
Charles (P = cte)
V₁/T₁ = V₂/T₂
Gay-Lussac (V = cte)
P₁/T₁ = P₂/T₂
Combinada
P₁V₁/T₁ = P₂V₂/T₂
Energía cinética y velocidad molecular
E_k = (3/2) · n · R · T
v_rms = √(3RT/M) = √(3k_BT/m)
  • M — Masa molar [kg/mol] · m — Masa de molécula [kg]
Procesos Termodinámicos
Isobárico (P = cte)
W = P · ΔV = n · R · ΔT
Q = n · Cp · ΔT · ΔU = n · Cv · ΔT
Isocórico (V = cte)
W = 0 → Q = ΔU = n · Cv · ΔT
Isotérmico (T = cte)
W = n · R · T · ln(V₂/V₁)
ΔU = 0 → Q = W
Adiabático (Q = 0)
P · Vᵞ = cte · T · V^(γ−1) = cte
W = −ΔU = −n · Cv · ΔT
γ = Cp/Cv : monoatómico = 5/3 · diatómico = 7/5
Ciclos y Eficiencia
Ciclo de Carnot — límite teórico máximo
η_Carnot = 1 − Tc / Th
η = W_neto / Q_absorbido
  • Tc — Temp. foco frío [K] · Th — Temp. foco caliente [K]
  • Ej: Th = 600 K, Tc = 300 K → η_max = 50 %
Refrigerador y Bomba de Calor
Refrigerador (COP)
COP_ref = Qc / W = Tc / (Th − Tc)
Bomba de calor (COP)
COP_BC = Qh / W = Th / (Th − Tc)
COP_BC = COP_ref + 1
Ciclo Otto (motor de nafta)
η_Otto = 1 − 1/r^(γ−1)
  • r = V_max/V_min — relación de compresión (típico 8–12)
Transferencia de Calor
Conducción — Ley de Fourier
Q/t = k · A · ΔT / L
R_térmica = L / (k · A) [K/W]
  • k — Conductividad [W/m·K]: Cu=385 · Al=205 · Fe=50 · aire=0.026
Convección — Ley de Newton
Q/t = h · A · ΔT
  • h — Coef. convección [W/m²·K]: aire natural 5–25 · agua forzada 1000–15000
Radiación — Stefan-Boltzmann
P = ε · σ · A · T⁴
P_neta = ε · σ · A · (T₁⁴ − T₂⁴)
  • σ = 5.67×10⁻⁸ W/m²·K⁴ · ε = emisividad (cuerpo negro=1)
Resistencia térmica en electrónica
R_th_total = R_jc + R_cs + R_sa
T_j = T_amb + P_disipada · R_th_total
  • R_jc — Junta→cápsula · R_cs — Cápsula→disipador · R_sa — Disipador→aire
